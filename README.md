# course-quiz-rag

Streamlit demo: upload a course (PDF) or pick a sample, and get an interactive quiz generated by a RAG pipeline. Each question shows the course passages that inspired it, and an **Architecture du RAG** tab displays the pipeline with its live parameters.

## How it works

PDF → text extraction (pypdf) → chunking → embeddings (`all-MiniLM-L6-v2`) → in-memory Chroma index → retrieval by **theme** → prompt → LLM (OpenAI-compatible API, OpenCode Go) → validated JSON (Pydantic) → quiz.

- The LLM answers in structured JSON (4 choices, `correct_index` 0-3, explanation, source chunk ids). Invalid output is retried once.
- Usage caps (per visitor and per day) protect the API quota. When a cap or the model quota is reached, the app serves pre-generated quizzes from `samples/` with a visible banner.
- Uploaded PDFs stay in memory for the session; they are never written to disk or logged.

## Run locally

```bash
python -m venv .venv
.venv/Scripts/python -m pip install -r requirements.txt   # Linux/macOS: .venv/bin/python
cp .env.example .env   # then export OPENCODE_API_KEY
.venv/Scripts/python -m streamlit run app.py
.venv/Scripts/python -m pytest
```

Without `OPENCODE_API_KEY` the app still runs and serves the pre-generated sample quizzes.

## Configuration

Environment variables (defaults in `.env.example`): `OPENCODE_API_KEY`, `LLM_BASE_URL`, `LLM_MODEL`, `MAX_PDF_MB`, `MAX_PAGES`, `CHUNK_SIZE`, `CHUNK_OVERLAP`, `TOP_K`, `VISITOR_DAILY_CAP`, `GLOBAL_DAILY_CAP`, `USAGE_DB`.

## Docker / Dokploy

```bash
docker build -t course-quiz-rag .
docker run -p 8501:8501 -e OPENCODE_API_KEY=... -v quiz-data:/data course-quiz-rag
```

On Dokploy, deploy from this GitHub repo with the Dockerfile build type, set the variables above in the environment tab, and mount a volume on `/data` so the usage counters survive redeploys. Port: 8501.

## Layout

- `app.py`: Streamlit UI (Quiz, Architecture du RAG, À propos)
- `rag/`: `ingest`, `retrieve`, `generate`, `pipeline`, `limits`, `fallback`, `architecture`, `config`
- `samples/`: two original sample courses and their fallback quizzes (`scripts/make_samples.py` rebuilds the PDFs)
- `notebooks/rag.ipynb`: the original exploration
